# Glossary

**stinger** - adjective that can be used to describe that something is associated with the stinger project.

**interface** - 

**contract** - This is the file that describes an interface: its name, methods, properties, signals, etc.

**server** - An MQTT client that provides functionality to stinger clients.

**client** - An MQTT client that consumes or utilizes functionality from a stinger server.

**service** - An instance of an stinger server.  This used to be called "instance".

**component** - The generic term used to describe parts of an interface: methods, properties, signals, or commands.

**pattern** - The behavioral design for a component.

**signal** - A fire-and-forget message sent from a server to its clients.

**command** - A fire-and-forget message sent from a client to a server.  It is the mirror image of a signal, or equivalently a method with no response: the client learns nothing about whether the server acted on it.

## Contract File Terms

**value** - In the contract file, this is the term for the name and type of a property's value.

**values** - In the contract file, this is the term for a list of values that is used for a signal's payload.
